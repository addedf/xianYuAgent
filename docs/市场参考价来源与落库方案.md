# 市场参考价来源与落库方案

> 调研日期：2026-09-25。本文是知识库重构一期的价格数据补充方案；录入、复核、关联线索、快照和停用已实现，真实可比成交样本及端到端过滤验收尚未完成；不包含实时行情报价。
> 适用范围：闲鱼手表、箱包、饰品线索的 `marketReferencePrice`。现行前置过滤条件为挂牌价低于参考价的 18%。

## 1. 调研结论

市场参考价不能由品牌均价、新品公价或某件在售商品的标价直接代替。二手商品需要先确认品类、品牌、型号或款式、成色、年份、附件、地区与价格口径，再比较价格。否则一件价格很低但型号、成色或附件不同的商品可能被错误过滤。

| 来源 | 本次核实到的能力 | 在本项目中的用途与限制 |
|---|---|---|
| 商家自己的已核实成交/回收记录 | 这是项目可掌握原始成交事实的来源；录入范围、真实性和样本量需由商家确认 | 优先用于同市场的可比价格；回收价与对外转售价须分开记录，不能混算 |
| [eBay Product research](https://www.ebay.com/help/selling/selling-tools/terapeak?id=4853) | eBay 官方说明可按品牌、成色、地点等筛选，查看历史成交价与成交区间；其研究结果包含议价成交的实际售价 | 可人工核对海外成交样本；币种、运费、税费和市场差异尚未换算前，不直接用于闲鱼 18% 硬过滤 |
| [Chrono24 Price analysis](https://update.chrono24.com/price-analysis/) | 官方说明腕表市场价以近期成交价为基础，并补充可比挂牌价；比较参考编号、成色、年份、附件等；页面明确未按国家/市场区分税费差异 | 腕表型号匹配和估价方法的参考；不能把跨境平台市场价直接当广州/佛山回收市场成交价 |
| [红布林官方介绍](https://hongbulin.com/about/) | 平台覆盖包袋、腕表、珠宝饰品，提供回收与寄卖，并有成色评级 | 可作为后续人工查价来源候选；具体同款页面、价格与评级能否取得仍需逐条核实。官网介绍不足以证明任意商品的实际成交价，本次也未验证可直接接入的价格数据接口 |
| [Vestiaire Collective Price Calculator](https://us.vestiairecollective.com/journal/discover-the-price-calculator/) | 官方说明通过品牌、品类、型号给出建议转售价 | 可作为人工估价的辅助参照；建议价不是已成交价，也不是本地回收价 |

以上来源只证明其页面所述的数据或估价能力，不代表已获批自动采集、批量导出或系统 API 权限。本期不依赖未经核实的第三方价格接口。外部平台的商品链接、价格与时间由人工核对后录入；任何后续自动接入先确认接口授权和使用条件。

## 2. 价格口径与准入

每条价格观察必须明确区分：`actual_sale`（已核实成交价）、`asking`（挂牌价）、`buyback_quote`（回收报价）、`estimated_resale`（估计转售价）及 `retail_msrp`（新品公价）。只有同一口径的样本才可汇总。页面不得把挂牌价称为成交价，也不得把回收报价称为市场零售价。

一期建议把“可用于前置过滤的市场参考价”定义为：**商家确认的、同市场同款或足够接近型号的二手转售参考价**，并附样本和调整说明。准入条件：

1. 型号或款式已核对；仅有品牌或宽泛品类时不给参考价。腕表尽量核对参考编号，箱包核对款式、尺寸和材质，饰品核对材质、规格及证书。
2. 成色、年份、附件和维修/改装差异有记录。不能确认关键差异时只给“待人工估价”，不启用 18% 过滤。
3. 记录价格口径、币种、观察日期、来源和证据链接。跨币种、跨市场样本未经人工换算与确认，不进入硬过滤。
4. 建议先用至少 3 条独立可比的近期成交样本求中位数，并记录调整依据；这是本项目的初始准入建议，仍需用真实商品校准，不是外部平台的统一标准。样本不足时，可显示单条参考观察，但不自动过滤。
5. 参考价过期或来源失效时停止用于硬过滤，保留历史快照供复盘。初始有效期建议 90 天，具体期限按品类校准。

价格很低也可能是真实捡漏。即使参考价合格，18% 命中仍需保留原商品与参考价证据、显示在“已过滤”视图，并支持人工解除过滤。参考价缺失或不合格时传 `null`，价格过滤器跳过；不能填 0、品牌均价或虚构默认价格。

## 3. 一期落库与评分契约

当前 `MarketplaceListing` 已有可选 `marketReferencePrice`，但 `marketplace_listings` 表未保存该字段，`loadLatestAssessedListings` 也未还原。采集器的搜索结果价格只是目标商品挂牌价，不是市场参考价。

建议一期新增版本化的 `market_price_references` 记录，至少保存：

| 字段组 | 必要内容 |
|---|---|
| 匹配范围 | 品类、品牌、型号/款式/参考编号、成色、年份、附件、地区或市场 |
| 价格观察 | 原金额、币种、价格口径、观察时间、来源名称与证据链接、样本数 |
| 参考价 | 人工确认的人民币金额、计算/调整说明、有效期、适用范围 |
| 治理 | 版本、录入人、复核人、复核时间、停用状态、修改原因 |

`marketplace_listings` 保存当前人工关联并批准的参考价 ID、版本、金额和过期时间；评估记录保存所用参考价 ID、版本、金额、币种和价格口径。不可变参考价记录保存观察时间、来源和复核信息，可按 ID 回溯。更新参考价使相关商品的评估指纹变化；过期或停用后页面把旧评估标为待重评。

一期只允许在知识后台把参考价人工关联到具体线索；未关联的型号资料仅展示，不自动匹配。批准准入要求为人民币、中国大陆二手市场、已成交口径、成色已核实、至少 3 条逐条录入的可比样本（来源或匿名成交编号、金额、日期）、观察时间在 90 天内。年份、附件、地区和差异说明分别保存。型号、成色和样本独立性的真实性仍由复核人判断，系统仅检查样本字段完整，不能自行证明外部成交真实。更细的自动匹配留待后续实施。读取持久化线索、采集导入和单条重评共享已批准关联价。试算接口接受人工输入的参考价，属于独立试算，不会改写商品关联记录。

## 4. 手动重新评分与成本

用户可以主动选择重新评分，包括对同一商品再次请求 JEV。自动采集路径对未变化的商品、规则和知识仍应复用已有评估，以免扫描重复产生模型费用。手动入口需明确告知“将重新调用 JEV”，并展示所用内容、规则、知识和参考价版本。

当前单条重评会在 JEV 调用后按 `(listing_id, input_fingerprint)` 冲突更新，因而同一指纹下的手动重评会覆盖旧结果。若允许用户主动重跑同一输入，应保留前次评分与本次调用的时间、原因、结果和成本审计，而不是静默覆盖；实施时可增加评估运行记录，或调整评估历史的唯一键设计。本文只确定交互与审计要求，不替用户决定是否发起本次调用。

## 5. 一期验收

1. 用一条人工核对的同款参考价，验证“录入/复核 → 匹配 → 商品保存 → 读取回显 → 试算 → 采集或手动重评 → 过滤证据与历史快照”一致。
2. 分别验证无参考价、过期参考价、只匹配品牌、币种未换算、成色冲突时，18% 过滤不执行，页面说明原因。
3. 修改或停用参考价后，相关商品不沿用过期的价格过滤评估；原评估仍能按当时版本复盘。
4. 验证自动重复扫描不新增 JEV 调用；用户明确选择重新评分时可以再次调用，并保留两次运行记录。
5. 在真实线索上抽查误杀，确认“已过滤”可见、可人工纠正。不能只以单元测试或总账页面显示“已启用”作为生效证明。
